# Day 12 Setup

From `ai_engineering/12_reliable_agentic_workflows`, use Python 3.11 or newer. The workflow uses only the Python standard library. Install `pytest` from the shared `../requirements.txt` if needed, then run `python -m pytest tests -q`.

Use `python workflow.py --help` for the local check and simulated create commands. A create requires an explicit terminal `CONFIRM`. The built-in festival dates and balances are fixtures, not live policy.
